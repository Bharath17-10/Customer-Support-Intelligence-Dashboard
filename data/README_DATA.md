# Dataset format

Place your dataset at `data/tickets.csv` with these exact columns:

- `ticket_text`: the customer's message
- `department`: one department label (for example Billing, Technical, Account, Shipping)
- `urgency`: one urgency label (for example Low, Medium, High, Critical)

Use a permitted dataset such as the dataset suggested in your project list, check its license/usage terms, and map its original columns and labels to this schema. Do not use the tiny examples in a report as evidence of model performance. Keep a separate untouched test split for final evaluation.
